# P1 双窗口手动验收清单

> **这份清单给谁看**：第一次接触这个项目、但完全不懂开发的人。
> 你不需要看代码，只需要照着做。
> **目标**：用**两个游戏窗口**把一局「镇长不在的时候」从头到尾玩一遍，看看它是不是真的能玩。

---

## 0. 怎么用这份清单

- 每一条验收项都写成三段：**怎么操作 / 看什么 / 过了没**。
- 全套做下来大约 15–25 分钟（其中 F 段要另外开两局）。
- 每条末尾都有一个空方框 `[ ]`：**过了**就打勾（写成 `[x]`），**没过**就在这一条下面补一句"卡在哪一步"。
- 中途卡住了别硬撑 —— 直接跳到 [第 4 节「怎么把问题报回来」](#4-怎么把问题报回来)，那里有现成的模板。
- ★ **开始之前请先把第 1 节做完**，那几步做错的话，后面全部会失败，而且现象会看起来像"游戏坏了"。

---

## 1. 把游戏跑起来（两个窗口）

### 1.1 需要准备什么

- 一台 Windows 电脑。
- 游戏程序和游戏项目文件（下面 1.3 会给出确切路径）。
- **两个游戏窗口的位置**：一个 1280×720 的屏幕放不下两个 → 拖到副屏，或者干脆用两个显示器。

### 1.2 第一次运行：先让游戏把素材导入一遍

如果这是**第一次**在这台电脑上玩这个项目，先跑一次导入，让游戏把图片素材准备好：

```powershell
& 'D:\Godot\Godot_v4.7.2-stable_win64_console.exe' --path D:\GodotProjects\after-hours --import
```

等它自己跑完（第一次可能几十秒）。之后再开窗口就不会缺素材了。

> 如果你平时用 Godot 编辑器打开这个项目，编辑器会自己完成这一步，这一步可以跳过。

### 1.3 开两个窗口（要**启动两次**）

在 PowerShell 里，**把下面这条命令运行两次**（一次开出一个窗口）：

```powershell
& 'D:\Godot\Godot_v4.7.2-stable_win64_console.exe' --path D:\GodotProjects\after-hours
```

> 路径按你机器上实际放的位置改。

跑起来之后你会看到**一个黑色的控制台窗口 + 一个游戏窗口**——这是正常的，那个黑色窗口是游戏自己的一部分，出问题时也要靠它报错。

两个游戏窗口都打开后，你会看到两个一模一样的大厅画面：标题是「**镇长不在的时候**」，中间有「**创建房间**」「**加入房间**」「**开始这一夜**」三个按钮。

### 1.4 为什么必须"启动两次"，不能一个程序里开两个窗口

一句话：**一个程序里开两个窗口，游戏只算你一个玩家。**

这个游戏联网时，每个玩家在网络里都有一个编号。房主的编号是固定的，而**加入方的编号是每次连上时随机发的一个 32 位大数**。如果两个窗口是同一个程序开出来的，它们共用同一套网络身份——网络那边会以为只有一个人，游戏逻辑也只会算你一个玩家。

所以必须**启动两次游戏程序**，让它真的是两个独立的程序、两个独立的网络身份。

（双击两次游戏程序的图标，效果一样。）

### 1.5 端口 28000（两个窗口用同一个端口）

两个窗口之间要互相找到对方，走的是本机的 **28000** 端口。

- **不需要你输入端口号** ——「加入房间」按钮已经写死了这个端口，你点一下就行。
- 但你要知道它是哪个端口，因为**房主那边是"开"这个端口、客户端那边是"连"这个端口**：
  - 端口被别的程序占着 → 房主窗口会显示「**创建房间失败（端口被占用？）**」。
  - 办法：**把之前没关干净的游戏窗口全关掉**（看任务栏有没有残留的游戏窗口），再重试一次。
- 28000 是这次人工验收**专用**的端口，不会和后台的自动化测试抢 → 所以**跑清单之前不用先停掉自动化测试**。

### 1.6 谁是房主、谁是客户端

| 窗口 | 角色 | 要点的按钮 |
|---|---|---|
| **窗口 1**（先打开的那个） | **房主** | 「创建房间」→ 后面「开始这一夜」「收工」也是它点 |
| **窗口 2**（后打开的那个） | **客户端** | 「加入房间」 |

### 1.7 键位

| 操作 | 按键 |
|---|---|
| 移动 | **方向键**（↑ ↓ ← →） |
| 捣蛋 | **按住 E**（松开就停） |
| 结束本局 | 右下角的「**收工**」按钮（鼠标点，只有房主能点） |

### 1.8 开局前的两条铁律（不满足会白跑）

① **两个窗口都要在点「开始这一夜」之前就位。**
回合开始**之后**才加入的客户端收不到"开局"这条消息 → 它会一直待在大厅里、不会进镇子。
这是这一版已知的限制（见 [3.1](#31-没做完--与计划不一致的地方)），**不是你的操作错了**。

② **先「创建房间」，后「加入房间」。**
客户端在房主建房之前就点「加入房间」是连不上的（等 8 秒后它会自己放弃回到大厅），重试即可。

## 2. 验收项

### A 一起开局

#### A1 房主创建房间 → 有提示

- **怎么操作**：在**窗口 1** 点「创建房间」。
- **看什么**：
  - 状态栏变成「**已创建房间，等待朋友加入…**」；
  - 名单区出现一行「**玩家 1**」；
  - 「**开始这一夜**」按钮从灰色变成**可以按下去**。
- **过了没**：[ ]

#### A2 客户端加入 → 有提示

- **怎么操作**：在**窗口 2** 点「加入房间」。
- **看什么**：状态栏变成「**正在加入…**」；**几秒内**两个窗口的名单区都变成两行「**玩家 1**」「**玩家 2**」，房主窗口的状态栏变成「**房间已创建 · 2 人在线，等人齐了开始**」。
- **注意**：如果**等了超过 8 秒**还是没连上，窗口 2 会自己放弃并回到大厅（它旁边的控制台里会有一行"连接超时"之类的提示）。→ 确认窗口 1 已经建好房，再点一次「加入房间」。
- **过了没**：[ ]

#### A3 两个窗口的名单都是 2 人

- **怎么操作**：对照窗口 1 和窗口 2 里的名单。
- **看什么**：两边都是「玩家 1」「玩家 2」**两行**，而且**顺序一致**。
- **过了没**：[ ]

#### A4 房主点「开始这一夜」→ 两个窗口都进镇子

- **怎么操作**：在**窗口 1** 点「开始这一夜」。
- **看什么**：
  - 两个窗口**同时**从大厅切进镇子画面（草地 + 散落的道具）；
  - ★ **玩家角色会晚大约 1.2 秒才出现** —— 这**不是 bug**，等 1~2 秒角色就会出来（原因见 [3.1](#31-没做完--与计划不一致的地方)）；
  - 角色出来后：屏幕**左上角**出现 **3 行**清单（每行前面一个空心方框「□」），**右上角**出现提示「**按住 E 捣蛋 · 已完成 0 条**」。
- **过了没**：[ ]

### B 领捣蛋清单

#### B1 左上角显示的是「自己那一份」

- **怎么操作**：看窗口 1 的左上角，再看窗口 2 的左上角。
- **看什么**：每边显示 **3 行**，每行一个「□ 标题」。**房主看到的也只是自己那 3 条**，不是全部人的清单——你的清单只有你自己该知道。
- **过了没**：[ ]

#### B2 张数 = 3

- **怎么操作**：数左上角有几行。
- **看什么**：**正好 3 行**。
- **怎么算出来的**：张数 = 人数 + 1，上限 5、下限 3 → 2 个人时 = **3 张**（1 个人也是 3 张，3 个人 4 张，4 个人及以上 5 张）。
- **过了没**：[ ]

#### B3 每条标题都读得通

- **怎么操作**：读左上角那 3 行。
- **看什么**：每行都是一句完整的中文，比如「偷走杂货铺的萝卜」「把广场椅子堆成塔」「拔掉街上的路灯」。**没有乱码、没有空白、没有半个句子。**
- **过了没**：[ ]

#### B4 两个窗口的清单不一样

- **怎么操作**：把窗口 1 和窗口 2 的 3 行**逐条**对比。
- **看什么**：**至少有一条不同**（两个人的清单不能是同一份）。
- **过了没**：[ ]

### C 执行捣蛋

#### C1 走到道具旁按住 E → 进度推进

- **怎么操作**：用方向键走到一个道具旁边（要**很近**，大约 1 格多），**按住 E 不松开**。
  - 提示：地图上每样东西长得都差不多（都是小方块），靠**贴图颜色**区分；走过去了对一下你的清单标题（比如「偷走杂货铺的萝卜」要找**萝卜**）。
- **看什么**：
  - 屏幕上**没有进度条**——这一版不画进度条，唯一反馈是右上角那个计数；
  - 保持按住 E，直到右上角的「已完成 0 条」变成「**已完成 1 条**」；
  - 大概要 0.5~3 秒（看是哪一条：有的 0.5 秒，有的要 3 秒）。
- **过了没**：[ ]

#### C2 完成一条 → 结果发给两个窗口

- **怎么操作**：完成一条之后，看**两个**窗口。
- **看什么**：
  - 完成的那个人自己的窗口：右上角「已完成 N 条」**加了 1**；
  - 对方窗口：**画面上不会有什么变化**（这一版不给已完成的条目打勾，右上角的计数也只显示**你自己**的条数）。
  - 所以这一条的判读标准是：**完成确实广播给了两个窗口**（否则你的完成在对方那边根本不生效），而**画面上的变化只有完成者自己看得到**。想验证"真的广播了"：让对方也完成一条，看**对方**那个窗口的数字有没有 +1。
- **过了没**：[ ]

#### C3 需要搭档的条目：没搭档时慢一倍

- **怎么操作**：如果你的清单里出现「**把广场椅子堆成塔**」或「**把长椅搬到池塘边看日落**」（这两种是需要两个人一起干的），做两次对比：
  1. **一个人做**：走到广场的椅子旁，按住 E，数一下用了多久；
  2. **两个人做**：两个人都走到**同一片**椅子旁（挨得足够近，大约 2 格以内），一起按住 E，再数一次。
- **看什么**：**两个人一起做明显更快**（大约是一半的时间：一个人约 6 秒，两个人约 3 秒）。
- **跳过条件**：如果你这一局的清单里**没有**需要搭档的条目，这条可以先跳过，在方框旁边写「本局没抽到，跳过」。
- **过了没**：[ ]

#### C4 同一个东西被两个人抢 → 先到先得，落败方不扣分

- **怎么操作**：两个人**同时**走到**同一个**道具旁（同一个萝卜 / 同一把椅子），一起按住 E，抢着做完。
- **看什么**：
  - **先做完**的那个人：右上角「已完成 N 条」**+1**；
  - **后做完**的那个人：右上角的数字**不变**——**没有 -1**，没有扣任何东西，也没有被踢出游戏；
  - ⚠️ **已知副作用**：那个道具这一局就被先到的人"占住"了，后到的人再去抢**同一个**道具还是抢不到 → 要换一个**同类的其它道具**（比如广场上有 4 把椅子）才能继续做。这一点记在 [3.1](#31-没做完--与计划不一致的地方)。
- **过了没**：[ ]

### D 被守卫抓

#### D1 守卫在巡逻

- **怎么操作**：进镇子后先别乱跑，站在原地看一会儿。
- **看什么**：镇子里有**一个守卫**（一个会自己走动的角色），他会**在自己那一小片地方来回走动**（大约 3~4 格的范围），不是站着不动。
- **过了没**：[ ]

#### D2 走进他的视野 → 他会追你

- **怎么操作**：走到守卫**正前方**（他面朝的方向），保持**不太近**（别贴到他身上，留 1~2 格），让他看见你。
- **看什么**：守卫**转身朝你冲过来**。
- **小提示**：他的视野是**正面一个约 80 度的扇形**，大约 3 格远。从他的**背后**走过去他不会发现。
- **过了没**：[ ]

#### D3 被抓到 → 被押送回自己的出生点

- **怎么操作**：故意让守卫抓到你。
- **看什么**：
  - **被抓的那个窗口**：屏幕**中间上方**弹出一句吐槽「**我的萝卜呢？！**」；同时你的角色**不再听你的键盘**，自己走回出生点，走回之后控制权还给你；
  - **另一个窗口**：能看见你的角色自己走回去；
  - 两个人的出生点**不一样** —— 开局时你俩站在镇子的**两个不同的位置**（一个更靠左下，另一个在附近但不是同一格）。
- **过了没**：[ ]

#### D4 被抓不会把进度清零（**要分两件事看**）

- **怎么操作**：
  1. **先完成一条**（右上角变成「已完成 1 条」）；
  2. 再挑一条**长的**（例如「把广场椅子堆成塔」，要 3 秒以上）按住 E，**在它做完之前**故意被守卫抓到；
  3. 被抓之后看两个数字。
- **看什么**：
  - **已完成的条数不变**：右上角还是「**已完成 1 条**」，**不是**「已完成 0 条」；
  - **手上那一条的进度作废**：被抓之后再按住 E 做刚才那条，要**从头再来一遍**（不能接着被抓前的进度继续）。
  - ★ 这两件事是**分开的**：被抓只作废**手上没做完的那一条**，**不动已经完成的条数**。
- **过了没**：[ ]

#### D5 守卫抓完人回到岗位继续巡逻

- **怎么操作**：让守卫抓你一次，然后盯着守卫看。
- **看什么**：守卫**先朝你走**（做出"押着你走"的样子），把你送到之后**自己走回原来那个岗位**（告示牌那格附近），然后**继续来回巡逻**。
- **过了没**：[ ]

#### D6 拔掉路灯 → 守卫视野变暗（这一版**没接上**）

- **怎么操作**：如果你的清单里有「**拔掉街上的路灯**」，走到路灯旁边按住 E 把它做完。
- **看什么**：**路灯不会真的灭，守卫的视野也不会变暗。**
  - 你能看到的只有：右上角的「已完成 N 条」**+1**；
  - **守卫照旧能看见你、照旧会追你**，视野一点没变。
- **怎么判定**：这一条按**已知问题**处理 —— 方框**保持不打勾**，旁边写「第 3 节已知问题 1：未接通」。等修好了再回来验这一条。
- **过了没**：[ ]　（预期为**不过**，这是已知问题）

### E 天亮结算

#### E1 房主收工 → 两个窗口都进结算页

- **怎么操作**：在**窗口 1**（房主）点右下角的「**收工**」。
- **看什么**：
  - 两个窗口**都**切到一个写着「**天亮了**」的页面；
  - 窗口 2 的「收工」按钮是**灰色**的（点不动）—— **这是设计如此**：只有房主能收工。
- **过了没**：[ ]

#### E2 每人一张「通缉令」

- **怎么操作**：看结算页中间的面板。
- **看什么**：每个玩家**一张卡片**，卡片上有：
  - 标题「**玩家 1**」「**玩家 2**」（这一版**没有玩家名字系统**，按出场顺序编号，两个窗口上编号一致）；
  - 一行「**捣蛋 N 次    被抓 N 次**」；
  - 下面是已完成的捣蛋**标题**（每条前面一个「·」）。
- **过了没**：[ ]

#### E3 没有分数、没有排行榜、没有淘汰

- **怎么操作**：把整个结算页从头到尾扫一遍。
- **看什么**：
  - 整个页面**只有**上面那些内容；
  - **没有**「得分」「分数」「排名」「第一名」「淘汰」「出局」这类字样；
  - 被抓**不会**让任何人的「捣蛋 N 次」变少，也**不会**让谁离场 —— 所有人都在这张结算页上。
- **过了没**：[ ]

### F 稳定

#### F1 一局 3~5 分钟能玩完

- **怎么操作**：从点「开始这一夜」开始，按平时的节奏玩；房主觉得差不多了就点「收工」。
- **看什么**：正常玩下来 3~5 分钟能玩完一局；**中途不会出现卡死、卡画面、必须重启才能继续**的情况；房主**随时**都能点「收工」结束（不用等满时间）。
- **过了没**：[ ]

#### F2 客户端中途退出 → 房主不崩

- **怎么操作**：开着局 → 直接把**窗口 2 关掉**（点右上角的 ×）。
- **看什么**：
  - **窗口 1 不崩、不卡死、不弹错误框**，画面还能继续操作（还能走动、还能捣蛋）；
  - 窗口 1 的「收工」按钮**依然可点**（能正常走完结算）；
  - 对方的角色**可能会**从画面上消失，**也可能**留在原地不动 —— **两种都算正常**，不影响你继续玩；
  - ⚠️ 这一版**对局画面上不显示在线名单**，所以"房主这边名单更新了"这件事**在画面上看不出来**，只能间接判断（房主还活着、还能继续玩、还能收工）。
- **过了没**：[ ]

#### F3 房主退出 → 本局结束（不做房主转移）

- **怎么操作**：开着局 → 把**窗口 1**（房主）关掉。
- **看什么**：窗口 2 会**跟游戏断开**：
  - 它**不会**自动接管当新房主（窗口 2 的「收工」按钮本来就是灰的）；
  - 这一局**不会**继续 —— 捣蛋再也没有人裁决了；
  - 画面上你可能还能走动（那只是本地还在动），但局面已经结束。
- **过了没**：[ ]

## 3. 已知问题 / 与计划的偏差

> 这一节讲的是"**现在就是这样，不是你操作错了**"和"**这一版还没做完的地方**"。验收时看到这些现象，请对照这里判断。

### 3.1 没做完 / 与计划不一致的地方

1. **拔掉路灯不会让守卫视野变暗（没接通）。**
   清单里如果有「拔掉街上的路灯」这一条，你**能把它做完**（计数会 +1），但**路灯不会灭、守卫视野不会变暗**。
   守卫"视野随灯变暗"这套机制本身是有的（每盏灭掉的灯让守卫视野缩到 60%），只是**"做完拔灯"和"灯真的灭了"之间那根线没接上**。
   → 对应 **D6**。

2. **多人局开局后，玩家角色会晚大约 1.2 秒才出现（不是 bug）。**
   房主会**故意等一小会儿**再把远端玩家放进来 —— 这是为了保证两个进程之间不出岔子的保守做法（实测过：去掉这个等待也能跑通，但那属于"看运气"，不能保证）。
   → 所以 **A4** 里"角色没立刻出现"是**预期行为**，等 1~2 秒就好。

3. **清单不会给已完成的条目打勾。**
   左上角那 3 行从头到尾都是「□ 标题」，做完某一条也不会变成「√ 标题」。完成情况**只能**从右上角的「已完成 N 条」计数看。
   → 影响 **C2** 的判读（这一版的已知限制，不是 bug）。

4. **对局画面上不显示在线名单。**
   所以"房主这边名单更新了"这件事**在画面上看不出来**，只能间接判断。
   → 影响 **F2** 的判读。

5. **被你抢输的那个道具，这一局就再也做不了了。**
   "先到先得"的记录**不会释放**。想继续做同类的事，得换一个**同类的其它道具**（广场上有 4 把椅子）。
   → 影响 **C4**。

6. **没有玩家名字系统。**
   名单和结算页上永远是「玩家 1」「玩家 2」，按**出场顺序**编号，两个窗口一致。

7. **结算里的「被抓 N 次」是本局的计数台账。**
   它统计的是"这一局被抓了几次"，不是某个角色身上的永久记录 —— 下一局重新从 0 开始。

8. **回合开始之后才加入的客户端会留在大厅。**
   它收不到"开局"那条消息 → 不会进镇子。**这一版接受这个限制。**
   → 所以 [1.8 的铁律①](#18-开局前的两条铁律不满足会白跑) 很重要。

9. **不做房主转移（host migration）。**
   房主一退出，这一局就结束；客户端**不会**自动接管。
   → 对应 **F3**，这是**预期行为**，不是故障。

### 3.2 占位素材带来的观感问题（都不影响玩法）

- 玩家角色是用 4 张方块小人的贴图轮流换的，**两个玩家可能长得一样**（取决于出场序号）。认人请靠**位置**和**屏幕角落的清单**。
- 守卫用的是**玩家的贴图**，不是专门的守卫造型 —— 他看起来就是个普通小人。
- **所有道具长得都差不多**（同一个形状换贴图）。萝卜、椅子、路灯、告示牌……请靠**贴图颜色** + **清单上的标题**区分。
- 地面是一块平铺的草地，**没有围墙**；镇子外面是空地，随便走。

### 3.3 已知的盲区（这一版**没有**测到的）

- 自动化测试只覆盖 **2 人局**；3~6 人局没有自动测过（界面上是支持 6 人的）。
- 「只有房主能收工」这类**权限校验**没有做恶意测试（例如客户端强行发一条收工指令）—— 正常玩法下不会碰到。
- 局域网（两台**不同的**电脑）**没测过**：这一版只保证**同一台电脑**上的两个窗口。

### 3.4 供对照：跑自动化测试时会看到的"正常现象"（你手动玩时不会碰到）

- 自动化测试用的是**别的端口**（不是 28000），所以和你手动玩互不干扰。
- 自动化测试的输出里会有故意的"连不上""失败"之类报错 —— 那是在测失败路径，不是坏了。

## 4. 怎么把问题报回来

### 4.1 先自己排查一下（多半能解决）

| 现象 | 多半是 | 怎么办 |
|---|---|---|
| 房主窗口显示「创建房间失败（端口被占用？）」 | 上次没关干净，还有别的游戏窗口开着 | 任务栏里把残留的游戏窗口全关掉，再点一次「创建房间」 |
| 客户端点「加入房间」8 秒后回到大厅 | 房主还没建房 | 先在窗口 1 建房，再回窗口 2 点「加入房间」 |
| 客户端进了大厅但没进镇子 | 加入晚了（开局之后才进来） | 两个窗口都退回大厅重来：先建房 → 再加入 → 最后点开始 |
| 角色没出现 | **正常**，要晚 1.2 秒左右 | 等 1~2 秒（见 [3.1 第 2 条](#31-没做完--与计划不一致的地方)） |
| 窗口卡住 / 画面不动 | 偶发 | 先试房主的「收工」；不行就两个窗口都关掉重开 |
| 守卫怎么都不看你 | 你在他背后 | 绕到他**正面**去（视野是正面约 80 度的扇形、约 3 格远） |
| 拔了路灯守卫还是看得见你 | **已知问题**，不是你的错 | 见 [3.1 第 1 条](#31-没做完--与计划不一致的地方) |

### 4.2 复现步骤模板

复制下面这段，填好发回来：

```
【环境】Windows 版本 / 显示器分辨率 / 发生时间
【游戏版本】4.7.2
【哪一步出的问题】清单第 X 条（X1 / C3 / D4 …）
【复现步骤】
  1.
  2.
  3.
【预期】应该看到……
【实际】我看到……（请描述你**看到的画面**，而不是推测的原因）
【是否每次都能复现】每次 / 偶尔 / 只出现过一次
【窗口 1 控制台里的报错行】
  （原样贴，别改写）
【窗口 2 控制台里的报错行】
  （原样贴，别改写）
```

### 4.3 需要附上的信息

1. **两个窗口的操作序列**：谁先点了什么、什么时候点的。
2. **控制台里的报错行**：每个游戏窗口旁边都有一个黑色控制台窗口，出问题时把里面带 `ERROR` / `WARNING` / `SCRIPT ERROR` 的行**原样**贴过来（不要改写、不要省略、不要只贴最后一行）。
3. **游戏版本**：4.7.2。
4. **出问题的清单编号**（比如「C3」「D4」）。
5. 能拍张照或录个屏更好。
